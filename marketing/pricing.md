# Pricing and limits

EasyHost costs $0 per month, with no credit card and no trial period. These are the limits.

## Limits

| Resource | Limit |
| --- | --- |
| Projects | 10 |
| Apps | 5 per project |
| Schedules | 5 per project |
| Storage buckets | 1 per project |
| Databases | 1 per project |
| Email senders | 1 per project |
| Emails | 20 per day, per project |
| Project members | 10 per project, including pending invites |
| AI Builder prompts | 30 per day, per project |
| Concurrent builds | 1 |
| App container | 512 MB RAM, 1 CPU |

## What it does not include

- Git integration or preview deployments
- An edge network or multiple regions
- Languages other than Node.js
