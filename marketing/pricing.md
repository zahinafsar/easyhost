# Pricing and limits

Hosting on EasyHost costs $0 per month, with no credit card and no trial period. The only paid item is AI Tokens for the AI Builder, after your first free AI app and build.

## Limits

| Resource | Limit |
| --- | --- |
| Projects | 3 |
| Apps | 3 per project |
| Schedules | 5 per project |
| Storage buckets | 1 per project |
| Databases | 1 per project |
| Email | Coming soon |
| Project members | 10 per project, including pending invites |
| AI Builder prompts | 30 per day, per project |
| Concurrent builds | 1 |
| App container | 512 MB RAM, 1 CPU |

## AI Builder tokens

Each account gets its first AI app and its first build free. After that, AI requests use AI Tokens. Tokens are bought once and never expire.

| Pack | Price |
| --- | --- |
| 500 tokens | $5 |
| 1,100 tokens | $10 |
| 2,400 tokens | $20 |
| 6,500 tokens | $50 |

Each request is charged by how much work it takes, and a typical full build is a few hundred tokens. Hosting an AI app stays free. See the [AI Builder](/products/ai-builder).

## What it does not include

- Git integration or preview deployments
- An edge network or multiple regions
- Languages other than Node.js

## Frequently asked questions

### Do I need a credit card?

No. Hosting needs no card. You only pay if you buy AI Tokens for the AI Builder after your free AI app and build.

### Is there a trial period?

No. There is no expiry date on the free plan.
