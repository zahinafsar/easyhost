Free Next.js hosting, with the backend included

EasyHost hosts Next.js apps for $0 a month. Each app runs in an always-on Node.js container with 512 MB of RAM and 1 CPU, gets HTTPS on its own subdomain, and can use a Postgres database, an S3 bucket and an email sender from the same free account. Signing up does not need a credit card.

How your Next.js app runs

EasyHost builds your project into a container image and runs it as a normal Node.js server with next start. Nothing is rewritten into serverless functions, so the app behaves the way it does on your machine.

  • Full Next.js server. Server rendering, route handlers, server actions, middleware and next/image all run inside your container.
  • Always on. The container is not stopped when traffic is idle, so the first request after a quiet night is as fast as any other.
  • Node 20, 22 or 24. Read from engines.node in package.json, otherwise Node 24.
  • npm, pnpm, yarn or bun. Detected from your lockfile.
  • Monorepos. Point the build at a subfolder with ezhst build set --root-dir apps/web.
  • Environment variables. Set with the CLI and passed to both the build and the running app, so NEXT_PUBLIC_ values work.

Build settings are auto-detected and can be overridden. See build settings.

Deploy in three commands

Run these inside your Next.js project folder. The CLI uploads your source, EasyHost installs, builds and starts it.

npx ezhst register
npx ezhst link
npx ezhst deploy

Or let a coding agent do it. Run npx ezhst skill install, choose Global or Local, and tell Claude Code, Cursor or Codex to "deploy this to EasyHost". The agent deploy guide shows how to load the instructions and deploy.

Your .env files are never uploaded. Import them once with ezhst env import .env.

What EasyHost does not do

Free hosting always has trade-offs. These are ours, stated plainly so you can decide before you deploy.

  • Node.js apps are supported, including Next.js and APIs.
  • Apps run in one region. There is no edge network or CDN in front of them.
  • There is no Git integration and there are no preview deployments. You deploy with the CLI.
  • 512 MB of RAM is enough for most Next.js apps, but not for heavy in-process workloads.
  • Files in a storage bucket are public to anyone who has the URL.

Frequently asked questions

Is there a catch to the free plan?

No trial and no card. The catch is the limits: 10 projects, 512 MB of RAM and 1 CPU per app, one region, and five Node.js apps per project.

Does a free Next.js app on EasyHost sleep when nobody visits?

No. The container keeps running, so there is no cold start after a period without traffic.

Can I host a full-stack Next.js app with a database for free?

Yes. Each project can have one Postgres database, one S3 compatible bucket and one email sender alongside the app, all free.

Do I need to change my Next.js project to deploy it?

No. There is no adapter, config file or output mode to set. The project needs a package.json with next and a build script.
