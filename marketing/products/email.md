# Transactional email

Send email from `<username>@easyhost.fun` with one HTTP request or one CLI command.

## What you get

- One sender address per project
- Text or HTML bodies
- An HTTP API authenticated with an API key
- A sent email log in the CLI

## Try it

```
ezhst email sender create acme
ezhst keys create production
ezhst email logs
```

## Limits

20 emails per day per project, and one sender. You send from an easyhost.fun address, not your own domain. See [pricing and limits](/pricing) for everything.
