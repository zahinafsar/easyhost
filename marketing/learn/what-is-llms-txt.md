## The short version

`llms.txt` is a proposed convention: a Markdown file at a site's root that summarizes the site for AI tools and links to its key pages. It gives agents a short, clean starting point instead of raw HTML. It is not a standard that every tool reads, so treat it as an addition to good documentation.
