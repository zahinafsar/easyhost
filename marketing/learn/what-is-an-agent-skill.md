# What is an agent skill?

An agent skill is a Markdown file of instructions that a coding agent loads when a task matches it.

## The short version

An agent skill is a Markdown file of instructions that a coding agent loads when a task matches it. It tells the agent which commands exist, the right order to run them in and how to handle failures. Skills are lighter than a custom integration because any agent that reads files can use one.

## On EasyHost

`npx ezhst skill install` adds the EasyHost skill. [Learn more](/products/agent-skill).
