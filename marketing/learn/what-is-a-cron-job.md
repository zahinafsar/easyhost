# What is a cron job?

A cron job is a task that runs automatically on a schedule, such as sending a daily report or cleaning old rows.

## The short version

A cron job is a task that runs automatically on a schedule, such as sending a daily report or cleaning old rows. Traditional cron runs commands on a server. Hosted schedulers usually call an HTTP endpoint instead, which works well with web apps because the job lives in your normal code. Protect those endpoints with a secret.
