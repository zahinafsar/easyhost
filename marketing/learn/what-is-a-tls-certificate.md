# What is a TLS certificate?

A TLS certificate proves that a server owns a domain and enables encrypted HTTPS connections.

## The short version

A TLS certificate proves that a server owns a domain and enables encrypted HTTPS connections. Certificate authorities such as Let's Encrypt issue them after checking that you control the domain. They expire and must be renewed, which is why platforms usually automate the whole process.
