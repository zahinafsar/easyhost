# What is server-side rendering?

Server-side rendering (SSR) builds HTML on the server for each request, then sends it to the browser.

## The short version

Server-side rendering (SSR) builds HTML on the server for each request, then sends it to the browser. Pages arrive with content already in place, which helps first load and crawlers. It needs a running server, unlike a purely static site, and that server uses memory for every render.

## On EasyHost

Frameworks such as Next.js, Nuxt and SvelteKit run in SSR mode on EasyHost. [Learn more](/frameworks).
