# What is a container?

A container is an isolated process with its own filesystem, built from an image that includes your app and dependencies.

## The short version

A container is an isolated process with its own filesystem, built from an image that includes your app and dependencies. It starts faster and uses less memory than a virtual machine because it shares the host's kernel. Containers are usually disposable, so lasting data belongs outside them.
