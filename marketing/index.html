What your agent can do

The whole platform, one authenticated CLI.

Every command takes --json and never prompts without a terminal, so agents get clean output and clear errors.

Create an account

Register, log in and check who is signed in, all without a browser.

ezhst register --name --email --password

Deploy Next.js

Package the folder, upload, build and go live on its own subdomain.

ezhst deploy

Environment variables

Set, unset or import a whole .env file. Applied on the next deploy.

ezhst env set KEY=VALUE

Build settings

Auto-detected by default. Override Node version, root dir or commands.

ezhst build set --node 22

Logs and build logs

Read runtime logs and the full build log, so the agent can fix what broke.

ezhst deployments log

Custom domains

Add a hostname, get the DNS record to set, verify and get HTTPS.

ezhst domains add shop.example.com

S3 storage

An S3 compatible bucket with public file URLs and its own keys.

ezhst storage create uploads

Postgres

A managed database with a connection string and a shadow DB for Prisma.

ezhst db query "select 1"

Transactional email

Send from you@easyhost.fun by CLI or one HTTP request. Every send is logged.

ezhst email sender create acme

API keys

Create and revoke keys your app uses to call the email API.

ezhst keys create production

FAQ

Questions people ask before they deploy.

Is EasyHost really free?

Yes. EasyHost costs $0 per month and signing up does not need a credit card. Every feature is included within fixed limits: 10 projects, and per project one Next.js app, one Postgres database, one storage bucket and one email sender with 100 emails per day.

What can I host on EasyHost?

Next.js apps. EasyHost runs next build and next start in a Node.js container, so server rendering, route handlers, server actions and middleware work as they do on your machine. Node 20, 22 and 24 are supported with npm, pnpm, yarn or bun.

Do free apps go to sleep?

No. Each app runs in its own always-on container with 512 MB of RAM and 1 CPU. It is not stopped when idle, so there is no cold start on the first request.

Which AI coding agents can deploy to EasyHost?

Any agent that can run shell commands. Claude Code loads the EasyHost skill after npx ezhst skill install. Cursor, Codex and other agents can read the same instructions from skill.md. The agent deploy guide has the steps for each.

Do I need to connect GitHub or change my project?

No. ezhst deploy packages the project folder and uploads it. There is no Git integration, no config file to write and no adapter to install.

Can I use my own domain?

Yes. Every project gets https://<name>.easyhost.fun, and you can add custom domains with ezhst domains add. HTTPS certificates are issued automatically once DNS is verified.

How is EasyHost different from Vercel?

Vercel runs Next.js on serverless functions behind a global CDN. EasyHost runs each app as one always-on container in a single region and includes Postgres, S3 storage and email in the same free account, all scriptable by a coding agent through one CLI. EasyHost has no preview deployments, Git integration or edge network. Read the full comparison.

Is the database a real Postgres?

Yes. Each project can have one Postgres 16 database with its own role, reachable over TLS with a standard connection string, plus a shadow database for prisma migrate dev. More on the free Postgres hosting page.
