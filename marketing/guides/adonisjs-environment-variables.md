# AdonisJS environment variables in production

`.env` files are never uploaded to EasyHost. Here is how to set variables for AdonisJS, and when each one takes effect.

## How AdonisJS reads variables

Variables are validated in `start/env.ts` and read with `env.get()`. Add every new variable to that schema, or validation will not cover it.

## Set your variables

```
npx ezhst env set APP_KEY=generate-with-node-ace-generate-key
npx ezhst env import .env
npx ezhst env list
npx ezhst redeploy
```

Variables apply on the next `deploy` or `redeploy`.

## What EasyHost provides

| Variable | Value | Available |
| --- | --- | --- |
| `NODE_ENV` | `production` | When the app runs, not during install or build |
| `PORT` | `3000` | Build and runtime |
| `HOST` | `0.0.0.0` | When the app runs |
| `HOSTNAME` | `0.0.0.0` | Build and runtime |

Your own variables are available in both the build and the running app.

## Frequently asked questions

### Are my .env files uploaded?

No. `ezhst deploy` skips every `.env*` file. Use `ezhst env set` or `ezhst env import`.
