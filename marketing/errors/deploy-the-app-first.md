# Deploy the app first

You tried an action, such as starting the app, before its first deployment.

## The error

```
Deploy the app first
```

## Why it happens

You tried an action, such as starting the app, before its first deployment.

## How to fix it

Deploy once, then try again.

```
ezhst deploy
ezhst start
```
